# Contributing to TheNovaNodes

First off, thank you for considering contributing to TheNovaNodes! It's people like you that make open-source a great community.

## How to Contribute

### Reporting Bugs
If you find a bug, please create an issue providing as much detail as possible. Include steps to reproduce, the expected outcome, and the actual outcome.

### Suggesting Enhancements
Have an idea for a new feature? We'd love to hear it! Open an issue detailing your suggestion and how it aligns with our mission as part of the Antigravity Agent Ecosystem.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the relevant test suite passes.
5. Make sure your code adheres to standard best practices and formatting guidelines across our tech stack (Go, Next.js, Python).
6. Issue that pull request!

## Code Guidelines
- Write readable, maintainable, and well-documented code.
- Ensure all comments and documentation are in high-quality English.
- Follow conventions appropriate for the specific project (e.g., standard Go formatting, Next.js best practices, or `pytest` for Python modules).
- Respect the modular nature of the TheNovaNodes collective.

We appreciate all contributions!
