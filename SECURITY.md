# Security Policy

## Supported Versions

The following versions are currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

Please report any security vulnerabilities via email to security@thenovanodes.com. Do not disclose vulnerabilities in public issues. We will respond promptly to all security disclosures.
