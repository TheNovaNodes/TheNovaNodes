# Welcome to TheNovaNodes 🌌

**Bridging the gap between Large Language Models and real-world infrastructure.**

## Our Mission

We build robust MCP (Model Context Protocol) gateways that seamlessly integrate Large Language Models with external tools and infrastructure. Our focus is on creating production-ready, open-source solutions for AI-powered workflows.

---

## Featured Projects

### 🌟 nova-anythingllm-mcp
**AnythingLLM MCP Gateway** — Semantic memory bridge for AI agents. Provides vector+lexical hybrid search across your knowledge corpus through the MCP protocol.

- **Tools:** `search_memory`, `get_document`, `gateway_health`
- **Features:** RRF fusion, context assembly, caching layer
- **Use case:** Connect LLMs to your internal knowledge base with enterprise-grade retrieval

### 🔍 nova-searxng-mcp
**SearXNG MCP Gateway** — Privacy-focused web search for AI agents. Meta-search across 80+ engines without vendor lock-in.

- **Tools:** `search_web`, `searxng_health`, `deep_research`
- **Features:** Streamable HTTP transport, semantic memory integration
- **Use case:** Give AI agents real-time web search capabilities with full privacy control
