# AI Agent Guidelines (AGENTS.md)

Welcome to TheNovaNodes! This document provides instructions and guidelines for AI agents interacting with this repository.

## Ecosystem Context
This repository is part of the **Antigravity Agent Ecosystem**. All changes must align with the goal of providing robust, production-ready, open-source solutions for AI-powered workflows.

## Guidelines
1. **High-Quality Documentation:** Ensure all documentation, including `README.md`, comments, and code explanations, is written in high-quality English.
2. **Standard Repository Structure:** Maintain the standard repository structure, which includes `README.md`, `AGENTS.md`, and `CONTRIBUTING.md`.
3. **Testing:** Write unit tests for new features and bug fixes whenever applicable to ensure the reliability of the tools. Use standard testing frameworks (e.g., `pytest`).
4. **Clean Code:** Adhere to Python best practices, keeping the codebase modular, readable, and well-documented.
5. **No Hallucinated Tools:** Only reference and use external dependencies, APIs, and tools that genuinely exist and are verified.

Thank you for contributing to TheNovaNodes and the Antigravity Agent Ecosystem!
